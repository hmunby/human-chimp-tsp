# Supplementary age figure

## `singer_age_dist/` — Supplementary Figure 2

The SINGER analogue of Figure 1A: the percentage of SNPs estimated to be older than a given age,
for shared SNPs (n = 18,788) against common 1000GP variants (n = 1,859,958). 

- `compute_singer_age_dist.py` — reads the 100-posterior SINGER age pickles and emits the
  uniform-branch survival curve on a 1,000-generation grid → `outputs/singer_age_dist.*.txt`.
- `plot_singer_fig1.py` — plots the two curve files.

The pickles need numpy 2.x; the curve files they produce are small and can be kept alongside.

### Input data

The posterior allele ages are **not ours** — they are the 100 posterior ARG samples that Deng,
Nielsen & Song (2025, *Nat Genet* 57:2124–2135) generated by running SINGER on 200 African
haplotypes from 1000GP. Download the per-chromosome tarballs from Zenodo:

| record | chromosomes |
|---|---|
| [10437053](https://zenodo.org/records/10437053) | 1–4 |
| [10467284](https://zenodo.org/records/10467284) | 5–10, 22 |
| [10467509](https://zenodo.org/records/10467509) | 11–21 |

```bash
wget https://zenodo.org/records/10437053/files/african_chr1.tar    # ...etc, per the table
```

Unpack, then reduce the tree sequences to the per-chromosome age pickles
(`african_chr{N}_ages.pickle`, mapping hg38 position → 100 (lower, upper) generation pairs) that
`compute_singer_age_dist.py` reads from `resources/ages_all/`. The unpacked tree sequences are
large and can be deleted once the pickles exist.

## Software
Python 3 (numpy 2.x for the pickles, pandas, matplotlib, scipy).
